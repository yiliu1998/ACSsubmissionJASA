# Code Repository for ``Targeted Data Fusion for Region-Specific Survival Effects in the AMP HIV Prevention Trials''

### Reproducing Figures E.14--E.16 (Additional Causal Contrasts)

The full simulation for these additional causal contrasts (RD, SR, and RMST) requires several days to complete. Therefore, we provide the intermediate `.RData` files so that reviewers can directly reproduce the summary statistics and figures without rerunning the simulations.

To reproduce these results, simply run:

```r
source("SumStat.R")
```

All required `.RData` files have already been prepared and are included in this repository.

The script `SumStat.R` generates the following PDF files:

| Manuscript Figure | PDF files generated by `SumStat.R` |
|-------------------|------------------------------------|
| Figure E.14 (Risk Difference, RD) | `relbias_RD.pdf`, `rrmse_RD.pdf`, `cp_RD.pdf` |
| Figure E.15 (Survival Ratio, SR) | `relbias_SR.pdf`, `rrmse_SR.pdf`, `cp_SR.pdf` |
| Figure E.16 (Restricted Mean Survival Time, RMST) | `relbias_RMST.pdf`, `rrmse_RMST.pdf`, `cp_RMST.pdf` |

Each manuscript figure is assembled from the corresponding three PDF files (relative bias, RRMSE, and coverage probability) generated by `SumStat.R`.
